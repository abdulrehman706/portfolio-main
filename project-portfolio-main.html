Portfolio Website

This dark-themed portfolio highlights my work as a Python Developer, AI Automation Engineer, and Full Stack Developer.

Project summary

  • Problem: I needed a single place to present my AI, backend, and full stack work in a modern, memorable way.
  • Solution: A customized Bootstrap portfolio with dark theme, animations, and dedicated sections for experience and projects.
  • Tech stack: HTML, CSS, Bootstrap 5, JavaScript (AOS, Swiper, custom interactions).

Problem statement

Generic CVs and simple profiles don’t communicate the blend of AI, automation, and full stack work I do. I wanted a portfolio that feels like a product: focused, animated, and clearly aligned with modern engineering.

Solution overview

This portfolio website includes:

  • A hero section with typed roles and animated gradient background.
  • About, Services, Projects, and Resume sections aligned with my current roles.
  • Scroll and hover animations (AOS, tilt effects) to give a modern product feel.
